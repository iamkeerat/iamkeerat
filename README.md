## Featured projects

### [DocuChat - Agentic RAG API](https://github.com/iamkeerat/DocuChat-Agentic-RAG)

Enterprise RAG API that ingests PDFs, retrieves grounding passages from ChromaDB, and runs a LangChain Researcher -> Critic workflow. The Critic checks every claim against the retrieved sources, triggers bounded revisions, and withholds answers it cannot verify. The service is containerised with Docker, tested with pytest, and checked by GitHub Actions CI. It supports Groq and local Ollama through OpenAI-compatible inference.

`Python` `FastAPI` `LangChain` `ChromaDB` `Docker` `pytest`

### [Healthcare Readmission Risk - SQL + ML](https://github.com/iamkeerat/Healthcare-Readmission-SQL-ML)

End-to-end SQL and machine learning pipeline over 5,000 synthetic patient records. The project covers relational database design, SQL feature engineering with CTEs and window functions, a leakage-safe Random Forest trained with GroupShuffleSplit, and evaluation focused on recall, ROC-AUC, and Brier score rather than headline accuracy.

`Python` `SQLite` `scikit-learn` `pandas`

### [Diabetes Prediction - Bayesian vs Classical ML](https://github.com/iamkeerat/Diabetes-Prediction-Bayesian-vs-ML)

MSc dissertation comparing an interpretable Bayesian network with logistic regression, Random Forest, XGBoost, and a neural network on the Pima Indians dataset. The analysis focuses on structure learning, probability calibration, and the trade-off between accuracy and interpretability.

`Python` `pgmpy` `bnlearn` `scikit-learn` `XGBoost`
